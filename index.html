Servidor Apache desplegado en AWS

Práctica de despliegue de un servidor web en una instancia EC2, con nombre de dominio propio y conexión cifrada mediante un certificado de Let's Encrypt.

Servidor en funcionamiento —

01 Qué hay detrás

Las cuatro piezas que hacen que esta página llegue a tu navegador.

AWS EC2

La máquina

Instancia virtual en la región us-east-1 con una IP elástica fija.

Apache 2.4

El servidor web

Sobre Debian GNU/Linux, con un VirtualHost para el dominio.

DNS

El dominio

Un registro de tipo A que apunta el nombre a la IP de la instancia.

Certbot

El certificado

Emitido por Let's Encrypt y renovado automáticamente cada 90 días.

02 Cómo se ha montado

El recorrido completo, desde el laboratorio vacío hasta el candado en el navegador.

  1. Lanzar la instancia EC2Debian, con un grupo de seguridad que abre los puertos 22, 80 y 443.
  2. Asignar una IP elásticaPara que la dirección pública no cambie al reiniciar el laboratorio.
  3. Instalar ApacheY sustituir la página por defecto por esta.
  4. Apuntar el dominioUn registro A en el DNS con la IP elástica de la máquina.
  5. Pedir el certificado con CertbotValidación por HTTP y redirección automática de HTTP a HTTPS.

03 Los comandos

Lo esencial que se ha ejecutado en el servidor.

admin@apache-servicios: ~
# Servidor web
$ sudo apt update && sudo apt install -y apache2
$ sudo systemctl enable --now apache2

# Certificado HTTPS
$ sudo apt install -y certbot python3-certbot-apache
$ sudo certbot --apache -d mi.dominio.com

# Comprobar la renovación automática
$ sudo certbot renew --dry-run
$
